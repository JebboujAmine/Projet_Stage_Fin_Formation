# Projet de Stage de Fin de Formation

## Description :
Ce projet est une application web de gestion développée dans le cadre du Stage de fin de formation.

## Technologies :
- **Backend :** PHP
- **Frontend :** HTML, CSS, JavaScript
- **Base de données :** MySQL

## Structure du projet :
- `SRC/` : Code source de l'application.
- `SQL/` : Scripts de la base de données.
- `ScreenShots/` : Captures d'écran de l'interface.
- `Documentation/` : Rapport de stage au format PDF.

## Installation :
1. Importer le fichier SQL se trouvant dans `/SQL` dans votre SGBD (ex: phpMyAdmin).
2. Placer le dossier `SRC` dans votre serveur local (ex: `htdocs` pour XAMPP).
3. Configurer la connexion à la base de données dans le fichier de configuration.

## Accès Administration (Back-Office)
Pour accéder à la partie administration :
- **URL :** `http://localhost/projet de Stage de fin de formation/authentification.php`
